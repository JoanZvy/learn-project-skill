# learn-project-skill
这是一个用于代码级详细学透整个项目的skill，能够生成一份直接用于学习细节的项目文档，适合作为简历内项目学习、需要学习底层逻辑原理、需要学习到代码实现程度而非简单了解、应对面试拷打的项目。

生成文档内包含：
/n1、项目介绍
2、完整大纲
3、功能级总结介绍
4、功能主函数接受参数
5、功能主函数源码
6、功能主函数内部调用流程
7、详细链路流程（一个一个函数的串联讲解大致功能）
8、核心函数源码与核心函数的函数内调用逻辑
9、核心函数内详细链路流程
10、章节关联即功能关联

行文逻辑：
1、覆盖全部函数，且为函数调用顺序，如a-b-c-d般串联覆盖全部项目内函数
2、功能串联，上下功能相连，行文顺序即程序运行顺序
3、逻辑顺畅，函数详细流程逻辑前后串联，流程逻辑即数据传输逻辑
